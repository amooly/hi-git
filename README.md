# Hi Git

A VS Code extension to visualize Git graph and compare branches/tags.

## Features

- **Workspace Git Graph**: Visualize your git history in a graph.
- **Git History**: View history of specific files or folders.
- **Compare**: Compare branches, tags, or local changes.

## Usage

Use the command palette (`Cmd+Shift+P` or `Ctrl+Shift+P`) and type "Hi Git" to see available commands.

## Requirements

- Git installed and available in your PATH.
